添加素材

从上方选择已有分类，或输入新分类后点“添加”；保存素材时使用的分类也会自动出现在这里。

最大 50 MB。上传后会读取实际音频时长。

JPG、PNG、GIF 或 AVIF，最大 5 MB，建议使用横图。不选择时使用默认封面。

支持整段或分段落。后端按标点自动分句，再根据音频时长与句子长度估算时间轴；这不是单词级强制对齐。

保存后会自动翻译成中文，显示在每句英文下方；翻译服务暂时不可用时，下次启动会重试。

可选，纯文本。一行写一个词条，换行会原样显示在学习页字幕下方；留空则隐藏该栏目。
